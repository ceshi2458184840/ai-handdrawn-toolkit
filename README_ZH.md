这个项目是基于ai-handdrawn-toolkit文档重构的，但进行了彻底升级和改进。专注于生产级AI手绘生成，包含物理级纹理着色器、高精度矢量化器、Master风格引擎等高级功能。同时严格遵循技能设计规范，确保代码质量和可维护性。

主要特性：
- 物理级手绘纹理引擎（石墨质感、纸张凹凸仿真）
- 高精度SVG矢量化（Spline样条曲线，断线自动修复）
- 三大利手风格预设（铅笔素描、建筑钢笔画、极简矢量线稿）
- MCP Agent技能支持（原生Claude Desktop集成）
- 防御性编程（统一异常层级、重试策略）
- 管道安全（stdout/json隔离，exit code标准化）
- 质量保证门禁（水印检测、风格检查、渲染质量）
- 中英文双语文档系统

严格遵循技能设计原则，符合生产环境要求。
